<h2 id="tentang">👨🏻‍🏫 Tentang SIBAS</h2>

Website Pelaporan Data Bank Sampah di Dinas Lingkungan Hidup dan Kehutanan Kabupaten Karawang

<p></p>

<h2 id="fitur">✨ Fitur Tersedia</h2>

- Autentikasi
  - Login user & admin
  - Daftar sebagai user dan admin
- Data Management
  - User dapat mengakses halaman user untuk pelaporan data sampah
  - Admin dapat mengatur semua yang ada didalam sistem website

<p></p>


<h2 id="syarat">💾 Prasyarat yang Diperlukan</h2>

Berikut adalah daftar layanan dan aplikasi yang wajib dan diperlukan selama anda menjalankan Website SIBAS

- PHP 8 & Web Server (XAMPP/Laragon)
- Web Browser 
- Internet

<p></p>

<h2 id="download">🐱‍💻 Panduan Menjalankan & Install Aplikasi</h2>

Untuk menjalankan aplikasi atau web ini kamu harus install XAMPP dan mempunyai setidaknya satu web browser yang terinstall di komputer anda.

```bash
# Clone repository ini atau download di
$ git clone https://github.com/rafizeazy/sibasv2.git

# Buat database
Buat database dengan nama "db_sibas" di DMBS (phpmyadmin, dll)

# Upload database
Upload file .sql yang ada difolder ke dbms phpmyadmin

# Running
Terminal > ketik php index.php
http://localhost:8080/


```
